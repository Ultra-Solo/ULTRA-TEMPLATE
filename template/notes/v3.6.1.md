## The runner operating system is pinned, not floating

Every workflow now names its Linux runner image explicitly — `ubuntu-24.04` for amd64 legs, `ubuntu-24.04-arm` for arm64 legs — instead of the floating `ubuntu-latest` label, which GitHub moves to Ubuntu 26.04 over October and November 2026. The required `verify` gate runs the same operating system on every day of that window, and a generated project's CI inherits the pin, so neither can fail because a label moved underneath a release. The image moves only by hand from here, like any other pin: validate on the explicit new label, move the pin in one release, say so in the notes ([ADR-0029](../docs/adr/0029-pin-the-runner-operating-system.md)). The hand-pinned tools golangci-lint, uv and trivy move to their current releases (2.14.0, 0.12.23, 0.75.0), and `source-map-js` advances to 1.2.2 in `apps/web` and `architecture`. The template version advances to **v3.6.1**.
