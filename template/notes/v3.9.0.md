## The template moves to Go 1.27

Go 1.27 was released 2026-08-19 and is at 1.27.2, but the template still pinned 1.26, so every project generated since August started one Go major behind — and 1.26's support ends when Go 1.28 ships (~February 2027). The template now pins Go 1.27, and the move happens in one release: the `go` line of `services/api-go/go.mod`, the `golang:1.27-alpine` digest in its Dockerfile, and the Dev Container go feature all move together, and `check-hygiene` rule 17 holds every copy to the declaration ([ADR-0032](../../docs/adr/0032-track-the-current-stable-go-line.md)). No generated code changes — Go 1.27 keeps the Go 1 promise of compatibility and the service uses only the standard library — so a project generated at v3.8.0 builds and runs on Go 1.27 unchanged, and only the toolchain declarations move, only on regeneration. The pinned golangci-lint 2.14.0 is built with go1.27.0, so the complete check runs on the new major. The hand-pinned uv moves 0.12.23 → 0.12.24 in every preset. The template version advances to **v3.9.0**.
