## The hand-pinned toolchain moves current

The Tuesday pins report of Oct 13 listed one stale tool; four more released in the three days after it, so this patch moves all five at once rather than publishing a release that is born stale. govulncheck moves 1.8.0 → 1.9.0, a routine refresh of the scanner's own Go dependencies published as a tag; zizmor moves 1.30.1 → 1.31.1, whose `dangerous-triggers` audit now treats `issue_comment` as fundamentally dangerous and whose `cache-poisoning` audit understands `cache-mode`; golangci-lint moves 2.14.0 → 2.15.0, a refresh of the linters it bundles; uv moves 0.13.0 → 0.13.1, a bug-fix release that does not change the lockfile format; and trivy moves 0.75.0 → 0.76.0. Every one is a development and CI tool: no runtime code changes, `uv.lock` is untouched, and every module's checks pass in this release's CI with the new versions installed from `scripts/tools/tools.json`. The template version advances to **v3.11.1**.
