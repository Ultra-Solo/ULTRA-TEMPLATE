## The refresh, folded into one path

This patch lands the two open dependency bumps and the three pin moves the 2026-10-27 pins report called for in one commit rather than merging them one at a time against a base each has already missed. The first is `github/codeql-action` v4.38.3 → v4.39.0, at its three usages — `init` and `analyze` in `codeql.yml`, `upload-sarif` in `scorecard.yml` — moved together so the action stays pinned at one SHA everywhere. The release raises the minimum CodeQL bundle to 2.20.7, which this repository does not pin against: no `tools:` input is set, so every run already resolves the current bundle. The same release validates the `analyze` step's `checkout_path` input, fixes cache restoration with third-party caching implementations, and aligns `start-proxy`'s release lookup with `init`'s.

The second is the Go service's runtime base: `gcr.io/distroless/static-debian13:nonroot` moves to the image build the registry now serves under that tag, digest `e2e927ec…` → `18f4cc26…`, as Dependabot resolved it. The tag is unchanged, so nothing about the image's contract moves — only the Debian package set under it. The digest is pinned, and the container-image probes that exercise the built image run in CI's `py-image-security` and chassis jobs.

The third is not a Dependabot bump but the plan's own trigger row: the `pins` run of Tuesday 2026-10-27 reported three hand-pinned tools not `current` — `uv` 0.13.3 → 0.13.6, `trivy` 0.76.0 → 0.76.1 and `mcp-publisher` 1.8.1 → 1.8.5. `node scripts/tools.mjs bump` moved each pin to the release the run named, checksums resolved from each release's record for every platform the tool ships — a pin is never moved from memory. The tools table in docs/toolchain-updates.md is generated from the pins, so it follows them rather than being edited beside them.

None of these moves closes an advisory against this repository's own dependencies, so in the plan's sense the batch is still freshness — but trivy 0.76.1 carries an upstream security mitigation worth naming: the release hardens the scanner against the eMudhra intermediate-CA compromise, its binaries built with the Go 1.27.3 certificate-distrust fix (CVE-2026-111943), and this repository runs that scanner in its own scheduled security scans. Dependabot opens these as two pull requests that each arrive after the other's base has moved on, so each alone fails `template-release-check` — the batch is the path the cadence already uses when that happens. The template version advances to **v3.13.8**.
