## The template moves to Node 26

Node 24 leaves Active support on 2026-10-20, and a generated project inherits the template's Node pin, so new projects were starting on a line about to leave Active support. The template now pins Node 26 — released 2026-05-05, at 26.11.1, entering Active LTS on 2026-10-28 — and the move happens in one release: `.node-version`, the `engines` of every `package.json`, the `@types/node` major, the `node:26-alpine` digests of both Node Dockerfiles, and the Dev Container node feature all move together, and `check-hygiene` rule 17 holds every copy to the declaration ([ADR-0031](../../docs/adr/0031-track-the-node-lts-line.md)). No generated code changes — Node 26 removes nothing the template uses — so a project generated at v3.7.1 runs on Node 26 unchanged, and only the toolchain declarations move, only on regeneration. The template version advances to **v3.8.0**.
