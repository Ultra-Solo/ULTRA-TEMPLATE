## The web app is proven in a real browser

`apps/web` gains a browser smoke test that runs where its component tests cannot reach: `scripts/e2e.ts` builds the app, serves the production bundle with `vite preview`, and drives it with a real Chromium against a running task service — a task created by keyboard, moved by click, still there after a reload, and a title the API refuses, with the board's reason for it in the alert. `node scripts/verify.mjs` runs the smoke automatically, against a task service on a free port with scratch data, and skips it with a message when the project has no task service. A Playwright trace is written to `test-results/` when a step fails, and its path printed. The template version advances to **v3.6.0**.
