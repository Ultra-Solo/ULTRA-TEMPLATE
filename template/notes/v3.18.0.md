## Clean generated projects of template meta-history

A template copy's git history was already fresh — GitHub copies the default branch as one initial commit, no tags — so ADR-0040 fixes the remaining file-level residue at generation time instead of rewriting the template's own immutable history. Every preset now starts `docs/adr/` at just `README.md` and `0000-template.md`: links that pointed at the template's records keep their label as plain text (a row in the ADR index goes entirely), `CHANGELOG.md` is reset to its `## [Unreleased]` heading with only the `Initialized from …` origin line, and the template-operational agent adapters (`.github/agents/release-cadence.agent.md`, `.github/agents/synthesis-architect-pro.agent.md`) are `templateOnly` paths, so no init copies them and no dangling `template/` reference ships. The template version advances to **v3.18.0**: generated output changes, the public contract does not, so this is a minor release.

What turns red: nothing in a generated project — its own `check-hygiene` and `check-docs` still pass with the records gone, because the links are rewritten rather than dropped. In the template itself, `template/init.mjs`, `template/clean.mjs`, and `template/features.json` are the files this release touches; an update that keeps local edits there is the likely conflict.
