## Dev Container security scan

The `security.yml` workflow now includes a `devcontainer-scan` job that builds the project's Dev Container image with Features, scans it with Trivy for HIGH and CRITICAL vulnerabilities, generates a CycloneDX SBOM, and records build metadata (base/final image digests, CLI version, platform) to the job summary and as artifacts. The job runs on every pull request and on the default branch.

The Dev Container CLI version is pinned via `scripts/tools/tools.json` and its install script is checksum-verified before execution. The base image digest is locked to `mcr.microsoft.com/devcontainers/base:ubuntu-24.04@sha256:d94c97dd9cacf183d0a6fd12a8e87b526e9e928307674ae9c94139139c0c6eae`.

This change adds the `devcontainer` feature to all presets that include `release`, and introduces the `devcontainer-scan` job to the security gate. The template version advances to **v3.2.0**.
