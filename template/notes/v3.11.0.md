## An architecture sparring agent in every generated project

Copilot selects an agent by the `name` and `description` frontmatter of a file under `.github/agents/` — the surface `check-docs` already validates, and which [AGENTS.md](../../AGENTS.md) already says wraps a task and defers to it. This release adds the first one: `synthesis-architect-pro`, a sparring partner for architecture decisions. It pressure-tests a proposal before anything is drawn: a premise check that determines whether replicated state is actually in scope rather than assuming it, at most two rounds of clarification, every choice reflected with its cost, a pairwise contradiction check that names mutually exclusive constraints and demands a choice, and at most two alternatives, each stating the condition under which it wins. Artifacts come only after an explicit alignment gate, and then the smallest set that answers the question: a C4 context diagram, a data-flow diagram with trust boundaries as the threat model's input, sequence diagrams only for flows that cross a process boundary, and an ADR-style decision record that marks every assumption. The file defers to AGENTS.md first; its rules govern the sparring procedure only. The template version advances to **v3.11.0**.
