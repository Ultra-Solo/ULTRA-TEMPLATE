## The template moves to Python 3.15

Python 3.15.0 was released 2026-10-09, and the template's policy is to track the current stable line ([ADR-0033](../../docs/adr/0033-track-the-current-stable-python-line.md)), so the move happens now rather than waiting for 3.14's bugfix window to close (~October 2027). The template now pins Python 3.15, and the move happens in one release: `services/api-py/.python-version`, the `python:3.15-slim` digest in its Dockerfile, and the Dev Container python feature all move together, and `check-hygiene` rule 17 holds every copy to the declaration. No generated code changes — the service is standard-library only, and its checks (ruff, mypy, pytest, the boundary check, the task-API contract) pass on Python 3.15 in this release's CI — so a project generated at v3.9.0 runs on Python 3.15 unchanged, and only the toolchain declarations move, only on regeneration. The hand-pinned uv moves 0.12.24 → 0.13.0 in every preset — uv 0.13.0 is the first release that knows 3.15.0 final — and `pyproject.toml`'s `required-version` moves with it to `>=0.13.0,<0.14`. The template version advances to **v3.10.0**.
