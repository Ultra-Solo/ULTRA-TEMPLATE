## Dependencies refresh in every module

Dependabot proposed this week's updates as five separate pull requests, one per module, but no one of them can merge alone: every Node module pins one Biome ([ADR-0012](../../docs/adr/0012-lint-and-format-typescript-with-biome.md)), and a change to generated output must advance the template version in the same change. The updates therefore land together, as one release: Biome moves 2.5.14 → 2.5.15 in `apps/web`, `architecture`, `packages/ts-library`, `services/api-ts` and `services/mcp-server`; `publint` moves 0.3.24 → 0.3.25 in `packages/ts-library`; and `vite` moves 8.3.1 → 8.3.2 with `vitest` and `@vitest/coverage-v8` at 5.0.2 → 5.0.3 in `apps/web`. Every one is a patch release of a development tool; no runtime code changes, and every module's checks pass in this release's CI. The template version advances to **v3.10.1**.
