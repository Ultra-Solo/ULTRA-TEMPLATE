## The refresh, landed ahead of the week's cadence

This patch lands the maintenance refresh in one path rather than waiting on the calendar. The hand-pinned toolchain moves one pin: uv 0.13.1 → 0.13.3, a bug-fix release that does not change the lockfile format and stays inside `pyproject.toml`'s `required-version` of `>=0.13.0,<0.14`; the new platform checksums come from the release's `.sha256` sidecars. Its two coupled copies — the generated block in the README and the toolchain table — move with it.

The module refresh is the drift Dependabot would have grouped on Monday, landed by hand instead: react 19.3.0 → 19.3.1 and react-dom 19.3.0 → 19.3.1, vitest 5.0.4 → 5.0.5 and @vitest/coverage-v8 5.0.4 → 5.0.5 in `apps/web`, and likec4 1.59.4 → 1.60.0 in `architecture`. Every one sits inside its caret range, so only lockfiles move; no manifest changes. The other three Node modules, the Go module and `uv.lock` are already current, which the refresh verified rather than assumed. The template version advances to **v3.13.3**.
