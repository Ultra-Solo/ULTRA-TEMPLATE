## The runners move to Ubuntu 26.04

Every Linux job in every workflow names `ubuntu-26.04` now, and the arm64 matrix legs name `ubuntu-26.04-arm` — 38 references across 13 workflows, moved ahead of the `ubuntu-latest` flip that GitHub completes on Nov 19. The move is deliberate, not early adoption by accident: the full gate — chassis, every preset's own verification, the devcontainer scan, the Python image security jobs on both architectures, zizmor, codeql, security and pins — already ran green on these exact labels with durations within ±9% of the 24.04 baseline, and the maintainer chose to move once that evidence existed rather than wait out the rollout window ([ADR-0034](../../docs/adr/0034-move-the-runner-pin-to-ubuntu-26.04.md), amending [ADR-0029](../../docs/adr/0029-pin-the-runner-operating-system.md)). The pin's discipline is unchanged: no workflow rides `ubuntu-latest`, the image moves only by hand with the gate validated on the new label first, and the Windows chassis job keeps `windows-latest` until GitHub announces a dated flip for it. Generated projects inherit the new labels through `init.mjs`, so their CI moves with this update.

actionlint 1.7.12's runner-label data predates the labels' general availability, so this release adds `.github/actionlint.yaml`, which declares the two labels through actionlint's supported configuration for labels its data does not know. It ships to generated projects and is removed in a later release once an actionlint release knows the labels natively.

The hand-pinned toolchain is already current from v3.11.1, so no tool pin moves in this release. The template version advances to **v3.12.0**.
