The template now uses its current GitHub owner, `Ultra-Solo`. Cloning the template itself no longer borrows `ULTRA-TEMPLATE` as a new project's repository name when `--name` and `--owner` are provided. New projects record the current upstream release URL; existing origin lines remain readable by the updater. If an old upstream URL is unavailable, pass `--template https://github.com/Ultra-Solo/ULTRA-TEMPLATE.git` explicitly when updating.

Registry namespaces are replaced in lowercase even when a GitHub owner uses mixed case. Active links, package metadata, Go module imports, and MCP image metadata agree with the template's current identity. Generated licenses retain the original MIT copyright notice and add the adopter's notice; updating an existing project may require resolving a locally edited `LICENSE`.

Full preset verification now feeds the template repository's required `verify` check on pull requests, main pushes, and merge queue entries. The call is removed from generated projects; their required-check name stays `verify`.
