## The weekly refresh, landed by hand

Dependabot opened its six grouped pull requests on Monday — the Go build image, four module dependency groups and the actions group — and all six are closed unmerged, as this repository's pattern requires: the refresh lands by hand, in one patch, with every action's SHA resolved from its release tag and every module's lockfile moving together. The module updates are the week's routine drift: `@types/node` 26.6.4 → 26.6.5 in every Node module, `zod` 4.6.5 → 4.6.6 in `services/mcp-server`, `@vitejs/plugin-react` 6.1.1 → 6.1.2, `happy-dom` 20 → 21 and `playwright` 1.63.0 → 1.64.0 in `apps/web`, and the `golang` 1.27 build image digest in `services/api-go`. The web group's major — `happy-dom` 21 — passes the component tests unchanged, proven on the Dependabot branch's own CI before it was closed.

The actions group moves four pins, each SHA resolved from its release tag: `actions/setup-node` v7.0.0 → v7.1.0 in every workflow and composite action, `github/codeql-action` v4.38.2 → v4.38.3, `actions/upload-artifact` v7.0.1 → v7.0.2 and `ossf/scorecard-action` v2.4.4 → v2.5.0.

The cadence agent's step 2 now enumerates the trigger table's scheduled workflows from the repository's workflow files, never from memory — the defect the single-path plan caught when a recalled inventory missed a workflow — and step 7 re-derives the table's workflow inventory the same way when the records are finished. The template version advances to **v3.13.2**.
