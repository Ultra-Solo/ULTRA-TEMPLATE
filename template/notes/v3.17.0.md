## A triage-and-fix procedure in every preset, and a hard cap on one contiguous edit

Two mechanisms ported from an external self-improving maintenance engine are now part of the template, each deterministic and gated ([ADR-0039](../../docs/adr/0039-port-only-verifiable-mechanisms-from-external-engines.md)): a human-operated **triage-and-fix** skill and prompt that walk scan → plan → dry-run → apply → verify → report, applying edits only through `scripts/search_replace.mjs`; and a new hard rejection in the mutation gate — no single contiguous changed hunk may span more than **10 lines** (removed plus added, measured on `-U0` diffs).

What ships:

- `.claude/skills/triage-and-fix/SKILL.md` and `.github/prompts/triage-and-fix.prompt.md`, owned by the `knowledge` feature, so every preset including `minimal` gets them. The skill asks the knowledge memory first, applies fixes only via `node scripts/search_replace.mjs --dry-run` and then the real run, verifies with `check-safety` and `verify.mjs`, and asks a human instead of guessing when anything is unclear.
- `scripts/check-safety.mjs` gains `MAX_HUNK_LINES = 10`: a contiguous hunk over 10 lines in a measured file is a hard rejection, alongside the existing 30%-deletion / 25-line file-level cap. Whole-file adds and deletes are still reported, not measured, and a genuine compensating rewrite is still allowed.
- `docs/adr/0039-port-only-verifiable-mechanisms-from-external-engines.md` records the port policy: only deterministic, check-verifiable mechanisms cross from external engines; agent roles cross as human-operated skills; autonomous write paths stay behind a dated backlog decision.

What can turn your build red:

- `chassis: check-safety` now fails a pull request whose staged diff contains one contiguous hunk over 10 lines in any measured file. Split the change into smaller hunks (several edits in one file are fine when they are separate hunks) or into separate commits; a wholesale rewrite of a file is still caught by the 30% deletion cap unless it is a compensating rewrite.
- `chassis: knowledge` runs `check` on `docs/knowledge/`: after this update, run `node scripts/knowledge.mjs sync` and commit `docs/knowledge/graph.json` and `docs/knowledge/README.md` with any change to docs, scripts, skills or ADRs.

Files an update may conflict on: `template/features.json` (version and the `knowledge` feature's paths), `scripts/check-safety.mjs`, `data/plan.md`, and the generated `docs/knowledge/graph.json` and `docs/knowledge/README.md` — on a conflict in the generated pair, take either side and run `node scripts/knowledge.mjs sync`. New files (`.claude/skills/triage-and-fix/`, `.github/prompts/triage-and-fix.prompt.md`, `docs/adr/0039-*.md`, `template/notes/v3.17.0.md`) merge cleanly.

Nothing is installed: both mechanisms are dependency-free Node and Markdown. The template version advances to **v3.17.0**.
