## The architecture model names both transports

The LikeC4 model still described the MCP server as exposing its tools "over stdio" after v3.7.0 added Streamable HTTP, so a project generated with the architecture feature shipped a model that did not match the server beside it. The model's description now names both transports, and the root README's module listing says how an adopter serves HTTP: set `MCP_TRANSPORT=http` ([ADR-0030](../../docs/adr/0030-serve-mcp-over-streamable-http-beside-stdio.md)). No check changes and no route changes; only those two descriptions move. The template version advances to **v3.7.1**.
